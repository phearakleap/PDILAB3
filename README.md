## Workflow

Each member will go through the same process to contribute to the code:
1. Create a new branch (standard naming for the branch is "practice" followed by the associated number e.g. "practice1").
2. Make a new folder within src/com/example/labs (same name as branch ideally).
3. Add the code, pseudocode, and flowchart into their working directory.
4. Stage and commit (with appropriate messages) changes.
5. Push into origin \<branch-name\>. DO NOT PUSH INTO MAIN/MASTER.
6. Wait for approval. The owner of the repository has the responsibility of checking the code and merging the changes into main/master.
